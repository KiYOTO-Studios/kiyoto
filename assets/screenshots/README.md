# App Sneak Peek Screenshots

Place your app sneak-peek screenshots in this directory.

Recommended files:
- `sneakpeek-1.png` (Studio Canvas / Main Workspace)
- `sneakpeek-2.png` (Computational Tools / Controls)
- `sneakpeek-3.png` (Unified Experience / Final Preview)

Recommended image format:
- Aspect Ratio: 16:10 or 16:9
- Resolution: 1920x1200 or 1280x800 (PNG or WebP)

In `index.html`, look for:
`<!-- REPLACE THIS SRC WITH YOUR SNEAK-PEEK SCREENSHOT FILE -->`
and set `src="assets/screenshots/sneakpeek-1.png"` (or any file path you choose).
